# Premier League Score Predictor

This project predicts **Premier League match outcomes** (Win / Draw / Loss) and expected goals using a **Poisson regression model** trained on FBref data.  

It also includes a **Streamlit dashboard** where you can interactively select two teams and get:
- Win / Draw / Loss probabilities  
- Expected goals for each team  
- Most likely scoreline  
- Visualizations (probability bar chart + scoreline probability heatmap)
